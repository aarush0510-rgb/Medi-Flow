# MediFlow – Hospital Management System

## Problem Statement

Managing hospital information manually can be time-consuming and difficult, especially when handling multiple patients, doctors, appointments, and user records. Paper-based or unorganized record systems can make it harder to store, update, and retrieve important information efficiently. This project solves this problem by providing a lightweight, terminal-based hospital management system that allows users to manage essential hospital operations through a simple command-line interface.

## Scope of the Project

The project is a command-line hospital management application designed to manage basic hospital operations. Scope includes:

- User registration and login for controlled access
- Managing patient records
- Managing doctor records and departments
- Booking and managing appointments between patients and doctors
- Generating unique IDs for patients, doctors, and appointments
- Generating appointment token numbers
- Storing and retrieving hospital data using JSON files
- Displaying records in a structured tabular format
- Generating reports based on stored hospital data

Out of scope (for this version): graphical user interface, online appointment booking, online payment processing, integration with real hospital databases, SMS/email notifications, and deployment as a web or mobile application. These can be considered as possible future enhancements.

## Target Users

- Hospital administrators and staff managing patient and doctor records
- Receptionists handling patient registration and appointments
- Students and beginner programmers studying Python-based management systems
- Evaluators reviewing the project as a Python console-based hospital management application
